# 📊 Sales Analysis Dashboard (Python + Power BI)

## 🔹 Project Overview
This project analyzes global sales data to identify revenue trends, top-performing products, regional performance, and profit distribution.  
The goal was to derive actionable business insights using data analysis and visualization techniques.

---

## 🛠 Tools & Technologies Used
- Python (Pandas, NumPy, Matplotlib)
- Power BI
- Excel
- DAX (Data Analysis Expressions)

---

## 📁 Dataset
The dataset contains transactional sales data including:
- Order Date
- Region
- Product Name
- Category
- Sales
- Profit
- Quantity

Data cleaning and preprocessing were performed using Python.

---

## 📌 Key KPIs
- **Total Sales:** 13M  
- **Total Profit:** 1M  
- **Total Orders:** 25.7K  
- **Total Quantity Sold:** 178.3K  
- **Profit Margin:** 11.6%

---

## 📈 Dashboard Features
- KPI Summary Cards
- Sales by Region (Bar Chart)
- Profit by Category
- Monthly Sales Trend (Line Chart)
- Top 10 Products by Sales (Funnel Chart)
- Year Filter (Slicer)

---

## 🔍 Key Business Insights
- Technology category generates the highest profit.
- Sales peak during Q4 (October–December).
- Top 10 products contribute more than 50% of total revenue.
- Certain regions significantly outperform others in revenue generation.
